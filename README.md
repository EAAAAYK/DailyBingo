# 日課ビンゴ ＆ 青空文庫（GitHubお試し版）

日課をビンゴ形式で楽しく続けられるWebアプリです。  
Google Apps Script (GAS) やサーバー設定を必要とせず、**ブラウザ単体（GitHub Pages）ですぐに動くお試し版**です。  
スマートフォン表示にも完全最適化されています。

---

## 特徴と機能

### 【今日】タブ
1. **4×4 ＆ 3×3 のデュアルビンゴ（合計25マス）**
   - 25個の日課項目を毎日自動でシャッフル配置。
   - 列（縦・横・斜め）がそろうたびに **+10 pt** 獲得。
   - チェックを外せばポイントも自動で連動調整されます。
2. **青空文庫から心に残る名文を毎日お届け**
   - 夏目漱石、太宰治、芥川龍之介、宮沢賢治、梶井基次郎、中島敦などの名作から厳選した一文を掲載。
   - 「別の3文」ボタンでいつでも新しい引用を読めます（青空文庫の図書カードへの実在リンク付き）。
3. **ご褒美システム**
   - 欲しいものや目標を金額（10pt = 10円換算）とともに登録・管理。
   - ポイントが貯まったら「交換済みにする」で達成感を味わえます。
4. **今日の達成状況**
   - 達成率、ビンゴ列、使用可能ポイント、累計獲得・使用を一目で把握。

### 【記録・ふりかえり】タブ
1. **今月のカレンダー**
   - 月送り対応のカレンダー。達成率に応じてマスが緑色に変化（ヒートマップ）。
   - ビンゴを達成した日は金色の枠線で華やかにハイライト！
2. **この頃のハイライト**
   - 過去7日・30日・90日のビンゴ列数グラフ。
   - よく達成した日課 TOP 5 を集計表示。
3. **ポイントの記録**
   - 直近30日の「獲得ポイント（緑）」と「使用ポイント（金）」の2色棒グラフ。
   - 累計獲得・累計使用・残高および交換内容の履歴一覧。
4. **日々の記録 ＆ CSVエクスポート**
   - 過去の日付ごとの達成項目・達成率一覧。
   - 「日課CSV」「ポイントCSV」の2種類をワンクリックでダウンロード可能（ExcelやGoogleスプレッドシートで開けます）。

## スマートフォン表示への対応
- スマホの縦長画面でも画面外へのはみ出しが発生しないレスポンシブ設計。
- 日課25項目編集モーダルは、スマホでは自動的に1列表示になり入力しやすくなっています。
- カレンダーや各種グラフも画面幅に合わせて柔軟にリサイズされます。

---

## 本番版（Googleスプレッドシート連携）について

本アプリは、Google Apps Script (GAS) 版（`daily-bingo-sync`）と連携させることで、**自分専用のGoogleスプレッドシートに日々の記録やグラフを自動集計・バックアップ**することも可能です。
`Index.html` はGAS環境にそのまま貼り付けても完全動作するハイブリッド設計になっています。
