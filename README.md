# 日課ビンゴ ＆ 青空文庫（GitHubお試し版）

日課をビンゴ形式で楽しく続けられるWebアプリです。  
Google Apps Script (GAS) やサーバー設定を必要とせず、**ブラウザ単体（GitHub Pages）ですぐに動くお試し版**です。

---

## 特徴と機能

1. **4×4 ＆ 3×3 のデュアルビンゴ（合計25マス）**
   - 25個の日課項目を毎日自動でシャッフル配置。
   - 列（縦・横・斜め）がそろうたびに **+10 pt** 獲得。
   - チェックを外せばポイントも自動で連動調整されます。

2. **ブラウザ保存（localStorage）で安心動作**
   - 面倒なログインやGoogle認証は不要。
   - 達成状況、履歴、設定、ご褒美データはお使いのブラウザに自動保存されます。

3. **青空文庫から心に残る名文を毎日お届け**
   - 夏目漱石、太宰治、芥川龍之介、宮沢賢治、梶井基次郎、中島敦などの名作から厳選した一文を掲載。
   - 「別の3文」ボタンでいつでも新しい引用を読めます。青空文庫の図書カードリンク付き。

4. **ご褒美システム**
   - 欲しいものや目標を金額（10pt = 10円換算）とともに登録。
   - ポイントが貯まったら「交換済みにする」で達成感を味わえます。

5. **積み重ねが見えるダッシュボード ＆ CSVエクスポート**
   - 過去7日・30日・90日のビンゴ列数グラフ。
   - よく達成した日課 TOP 5 を集計。
   - 「日課CSV」「ポイントCSV」の2種類をワンクリックでダウンロード可能（Excelやスプレッドシートで分析可能）。

## GitHub Pages での公開手順（3分で完了）

1. **GitHubに新しいリポジトリを作成**（Public推奨）。
2. このフォルダ内のファイル（`index.html` と `README.md`）をリポジトリのルートにアップロード（または `git push`）。
3. リポジトリの **Settings** タブを開く。
4. 左メニューの **Pages** を選択。
5. **Build and deployment** の Source で `Deploy from a branch` を選択。
6. Branch を `main`（または `master`）、フォルダを `/ (root)` にして **Save** をクリック。
7. 数十秒〜1分ほどで公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が発行され、スマホやPCのブラウザから誰でもアクセスできるようになります！

## 本番版（Googleスプレッドシート連携）について

本アプリは、Google Apps Script (GAS) 版（`daily-bingo-sync`）と連携させることで、**自分専用のGoogleスプレッドシートに日々の記録やグラフを自動集計・バックアップ**することも可能です。
スプレッドシート連携版のコードや導入方法は、`daily-bingo-sync` フォルダをご確認ください。
